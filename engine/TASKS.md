## Important cautions

- Do not regress sidebar page selection. Any page must remain selectable in every view mode.
- Do not reintroduce a persistent native PDFium link handle. Engine link parsing now uses an immutable in-memory document cache.
- Bookmark hierarchy replacement changes bookmark object identities. The sidebar already rebuilds after each edit and uses path-based expansion restoration during reload.
- Named destinations must remain intact when bookmarks are rewritten.
- The desktop temp-reload path strips native page rotations before engine finalization and restores application rotation state after reopening. Preserve that ordering.
- Do not wire signature invalidation cleanup into ordinary Save while the live PdfSharpCore document can retain stale signature state.
