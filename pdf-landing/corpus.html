Public corpus, full private gate

The downloadable release contains 16,696 general regression PDFs, 552 standards PDFs, and 80 malformed fuzz inputs. Every public file has a recorded source, size, and SHA-256 fingerprint.

The maintainer workstation adds 29,599 PDF Association Stressful PDF files and 97 Altona and Ghent color-suite files. Those files are not republished, but their sources, hashes, and external qpdf baselines remain recorded. Restricted redistribution does not make them invisible to the test program.

A baseline that can be repeated

  1. Use the exact signed KillerPDF release payload and record its SHA-256 hash.
  2. Warm each PDF collection once.
  3. Run each PDF collection five measured times while keeping the workstation otherwise idle.
  4. Require identical outcome counts across every measured pass.
  5. Report the median time, plus the minimum and maximum.
  6. Keep malformed security inputs in a separate crash and timeout gate.

The published CSV files contain every measured collection time and a comparison-ready summary. The detailed benchmark document also records the operating system, processor, memory, storage class, and executable hash.

What the results mean

OK

KillerPDF opened and saved the input through the tested batch path.

Skipped

The input was intentionally refused or could not enter that path, such as an encrypted, unsupported, or unreadable file.

Failed

The input entered the operation but the save did not complete. A failed save is not an application crash.

These results measure safe batch open and save behavior. They do not claim rendering, text extraction, layout reconstruction, or semantic table recovery.
